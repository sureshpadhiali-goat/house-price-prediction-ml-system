#  House Price Prediction using Machine Learning

##  Project Overview
This project predicts house prices using multiple regression models. It is an end-to-end Machine Learning system with data analysis, model building, API deployment, and frontend integration.

##  Features
- Data Analysis (EDA)
- Feature Engineering
- Multiple ML Models (Linear, Ridge, Random Forest, etc.)
- Model Comparison
- FastAPI Backend
- Streamlit Frontend

##  Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- FastAPI
- Streamlit

##  Dataset
- Kaggle House Prices Dataset
